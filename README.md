## Bangladeshi Food Detection

This project provides an end-to-end workflow for Bangladeshi food object detection using deep learning. The Jupyter notebook [Bangladeshi_Food_Detection.ipynb](https://github.com/atikur234/BangladeshiCuisine/blob/main/Bangladeshi_Food_Detection.ipynb) demonstrates:

- **Dataset Download via Roboflow** — Downloads the "Bangladeshi Street Food" dataset in YOLOv8 format for training and validation.
- **Modern Object Detection** — Uses the YOLOv8 model with Ultralytics PyTorch implementation for custom training on Bangladeshi food items.
- **All-in-One Training Script** — Handles data preparation, model training, evaluation, and visualizations (Precision, Recall, mAP, Confusion Matrix, Training Curves).
- **Colab-Friendly** — The notebook is designed to run on Google Colab and Kaggle with required environment setup steps.
